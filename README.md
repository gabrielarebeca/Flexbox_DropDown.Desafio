# Flexbox DropDown - Desafio

Este repositório apresenta uma solução para um desafio de criação de menu dropdown utilizando **Flexbox**. O objetivo foi treinar habilidades em **HTML** e **CSS**, com foco em responsividade e layout moderno.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (com Flexbox)

## 🎯 Objetivo

Criar um menu dropdown funcional e estilizado, utilizando apenas HTML e CSS, sem uso de JavaScript. A estrutura foi organizada para garantir clareza, simplicidade e boas práticas de codificação.

## 📌 Funcionalidades

- Layout responsivo com Flexbox
- Menu dropdown ao passar o mouse (hover)
- Estilo limpo e organizado
